Usage: gotmpl2text [OPTIONS] [FILE...]

A CLI filter for testing and rendering Go templates with YAML/JSON data.

Reads template from STDIN, outputs rendered result to STDOUT.

Options:
  -h, --help        Display help message
  -m, --man         Display full readme         (tip: gotmpl2text --man | colored-md)
  -v, --version     Display version information (tip: gotmpl2text --version | jq -r .Version)
      --helm        Inject dummy Release/Chart/Capabilities/Template context as
                    defaults (overridable by any downstream data)
  -w, --wrap KEY    Wrap every subsequent data file under top-level KEY before
                    deep-merge; repeat with a different KEY to switch mid-list
                    (embedded __DATA__ blocks are NOT wrapped)

Environment:
  GOTMPL_ALLOW_MISSING  Set to 1 to allow missing keys (renders <no value>)
  GOTMPL_IGNORE_EMBED   Set to 1 to ignore embedded __DATA__ blocks
  GOTMPL_FUNCTIONS      Path to custom functions YAML file
  GOTMPL_PRELOAD        Colon-separated list of template files to preload (semicolon on Windows)
  GOTMPL_DEBUG          Set to 1 to enable debug mode (diagnostic output to stderr)

Examples:
  gotmpl2text < template.tmpl base.yaml override.yaml

  gotmpl2text <<< '{{ .name }}' <(echo '{"name":"test"}')

  gotmpl2text --wrap Values < snippet.tmpl chart/values.yaml override.yaml

  gotmpl2text --helm ctx.yaml --wrap Values < snippet.tmpl chart/values.yaml
